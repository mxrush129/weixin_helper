# 微信群聊助手

这是一款 Windows 桌面小工具。群消息和生成的总结保存在项目下的 `data/wechat.sqlite3`。

## 采集群聊

1. 打开并登录电脑版微信。
2. 双击 `启动.cmd`。首次启动会用本机 Python 创建虚拟环境并安装依赖。
3. 输入微信里的完整群名，点「添加群聊」。只监控一个群时，可以让微信主窗口停在该群。监控多个群时，在微信会话列表双击各群以打开独立聊天窗口。
4. 点「开始监控」。确认群的状态显示「已连接」。保持微信和助手运行，并让目标聊天窗口停在最新消息处。群窗口最小化后会暂停读取。采集默认每秒一次，可以调到 0.5 秒。

首次连接会保存当时能读到的消息。程序读取 Windows [UI Automation](https://learn.microsoft.com/en-us/windows/win32/winauto/uiauto-uiautomationoverview) 提供的聊天控件。采集时间以本机时钟为准，微信在列表里给出时间标签时也会保存。语音、视频和文件只记录微信提供的文字描述。移除监控会保留该群已存的内容，重新添加同名群可以继续查看。

**撤回消息**会按采集时看到的内容处理。已入库的原文和已保存的图片会一直保留，能读到的撤回提示也会保存。两次采集之间就被撤回的消息、微信没显示过的消息，以及开始监控前已撤回的原文都可能缺失。撤回提示通常没有可用的消息编号，因此界面会单独展示。

## 保存和解析图片

- 默认勾选「自动保存图片截图」。助手在后台获取微信聊天窗口的画面，裁出消息图片并保存为 PNG。采集期间可以继续工作，助手也可以最小化。目标微信群窗口保持打开并停在最新消息处，可以被其他窗口遮挡。微信群窗口最小化或系统拿不到有效画面时，图片会暂时等待保存。
- 自动保存使用微信显示尺寸的截图。保存成功后，在消息记录里点「打开图片」。图片文件在 `data/images/`，相同文件只存一份。显示「图片待保存」时，可以在微信手动另存，再从该消息右边的「导入图片」添加。
- 在「模型设置」里填好 DeepSeek Flash 的密钥后，可以点单张图片旁的「解析图片」。助手会保存图片描述、可辨认的文字和图表要点。生成群聊总结时，DeepSeek Flash 会先解析所选时间段内已保存但尚未解析的图片，再将结果纳入总结。[DeepSeek 图片输入文档](https://api-docs.deepseek.com/guides/vision/)

## 生成 AI 总结

- **DeepSeek（默认）**。地址预填 `https://api.deepseek.com`，模型预填 `deepseek-flash`。在「模型设置」里填一次 API 密钥，Windows 会将其加密保存在 `data/deepseek-key.dpapi`，供当前 Windows 用户下的助手使用。更换密钥时重新填写即可。也可以在启动前设置 `DEEPSEEK_API_KEY` 环境变量。[DeepSeek 接口文档](https://api-docs.deepseek.com/zh-cn/) · [Windows 数据保护说明](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)
- **其他模型 API**。在「模型设置」中填写 OpenAI 兼容的 HTTPS API 地址、模型名和提供方要求的密钥。密钥只在运行时使用，也可在启动前设置 `WEIXIN_HELPER_API_KEY` 环境变量。
- **本机模型**。使用 Ollama 时，将地址改为 `http://127.0.0.1:11434/v1`，模型填本机已下载的模型名，例如 `qwen3:4b`。本机 Ollama 可留空密钥。[Ollama 接口文档](https://docs.ollama.com/api/openai-compatibility)

选中一个群，打开「AI 总结」，按采集时间选择范围，再点「生成 AI 总结」。启用云端接口时，手动点击解析或总结才会向模型服务发送对应的图片和消息。生成结果会保存在本机，切换群时可以看到各群最近一次总结。
